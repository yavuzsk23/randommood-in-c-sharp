
# English

This project is a C# console application that prints a random mood to the console.

What does it do?
It selects a random mood from a defined list and prints it to the screen.



# Deutsch

Dieses Projekt ist eine C#-Konsolenanwendung, die eine zufällige Stimmung in der Konsole ausgibt.

Was macht sie? Sie wählt eine zufällige Stimmung aus einer definierten Liste aus und gibt diese auf dem Bildschirm aus.
